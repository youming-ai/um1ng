# um1ng

[um1ng.me](https://um1ng.me) · 个人主页，跟随鼠标转动的线框与粒子骷髅头。

Vite + Void · 原生 WebGL · Cloudflare Workers，无运行时依赖。

## 使用

需要 Bun 和 Node.js 22+。

```sh
bun install
bun dev          # 本地开发
bun run build    # 构建到 dist/client
bun preview      # 预览构建
bun run deploy   # 部署已有构建，需先运行 build
```

贡献与项目结构说明见 [AGENTS.md](AGENTS.md)。
